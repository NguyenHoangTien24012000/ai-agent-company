# Báo cáo lane L1

## Kết quả

Đã triển khai toàn bộ CLI trong CONTRACT, server board dùng chung `Company.resolve_ask`, và bộ chờ sự kiện có lọc phòng/loại. Mã chỉ dùng thư viện chuẩn Python 3 và Bash.

- Mọi thao tác ghi giữ `fcntl.flock` trên `state/.lock`, thay file JSON/board bằng file tạm + `os.replace`, nối một dòng sự kiện rồi sinh lại `data/board.js`. Giờ có múi `+07:00`.
- CLI hỗ trợ `--json` ở đầu, giữa các cấp lệnh hoặc cuối lệnh; lỗi đầu vào exit 2, tranh chấp chìa khoá app exit 3 và báo phòng giữ.
- Resolve `ok` ghi gate; câu hỏi đã resolve không bị ghi đè; bug đi đúng vòng open → fixing → retest → closed và chỉ QA được đóng.
- `room done` nhả chìa khoá nếu giữ và chỉ in lệnh dọn worktree. Một sự kiện `room_done` có `keyReleased=true` ghi nhận việc nhả khoá trong thao tác này.
- Snapshot gồm phòng active, phòng done trong 7 ngày theo `updatedAt`, hàng đợi ask/bug cần Sếp theo thứ tự cũ trước, và 50 sự kiện mới nhất theo thứ tự mới trước.
- Server chỉ cấu hình bind `127.0.0.1`, phục vụ đúng các đường dẫn cần thiết, yêu cầu JSON + `X-Company: 1`, kiểm tra Origin, trả câu hỏi đã resolve và ghi `via=board`.
- `wait-event.sh` bỏ qua dữ liệu có trước lúc bắt đầu, lọc đồng thời `--room`/`--types`, xử lý dòng ghi dở và file đổi inode, exit 2 khi hết giờ.

## Kiểm thử đã chạy

Lần đầu:

```text
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
Ran 15 tests in 10.989s
FAILED (errors=1)
```

15 test CLI/waiter đều qua. Lỗi ở khởi động server TCP: `[Errno 1] Operation not permitted` vì sandbox chặn bind localhost. Đã bổ sung transport HTTP trong bộ nhớ để kiểm tra handler thật, giữ lớp kiểm thử TCP riêng; lớp này chỉ skip khi khởi động server báo lỗi quyền.

Lần cuối, tại `/Users/tien/sportshub-company` (export `PYTHONDONTWRITEBYTECODE=1` để không tạo cache trong repo):

```text
python3 -m unittest discover -s tests -v
Ran 20 tests in 11.315s
OK (skipped=1)
```

20 test đã chạy đều qua. Một lớp `LiveServerTests` skip ở `setUpClass` do sandbox, không có lỗi assertion bị bỏ qua. Các kiểm thử HTTP trong bộ nhớ đã xác nhận GET, 403 khi thiếu/sai header hoặc Origin, resolve hợp lệ với ba trường hợp Origin, từ chối body/choice sai và câu trả lời trùng. Kiểm thử 20 tiến trình ghi giữ đủ 20 ask với ID riêng, đủ 21 sự kiện tính cả mở phòng, và board khớp state. Waiter chạy tiến trình Bash/Python thật với timeout ngắn.

Các kiểm tra bổ sung:

```text
bash -n bin/wait-event.sh
# exit 0
python3 - <<'PY'
import ast
from pathlib import Path
for name in ('bin/company.py', 'bin/board-server.py', 'tests/test_company.py', 'tests/test_server.py'):
    ast.parse(Path(name).read_text(encoding='utf-8'), filename=name)
    print('Cú pháp OK:', name)
PY
# Cả 4 file: Cú pháp OK, exit 0
```

## Điểm cần lưu ý

- Hợp đồng không có `doneAt`; cửa sổ 7 ngày dùng `updatedAt` của phòng done.
- JSON từng file và board được thay nguyên tử; nhiều file cùng một thao tác được bảo vệ khỏi ghi đồng thời bằng khoá, nhưng không phải giao dịch phục hồi khi tiến trình chết giữa các lần ghi file.
- Câu hỏi `quyet`/`thaotac` không có options nhận choice chuỗi không rỗng; nếu có options thì choice phải khớp. `duyet` bắt buộc có gate và option `ok`.

## Blocked On

Cần chạy lại `python3 -m unittest discover -s tests -v` trong terminal cho phép bind TCP localhost để xác minh lớp `LiveServerTests` qua mạng thật. Sandbox hiện tại chặn thao tác này và không cho yêu cầu nâng quyền. Không cần mở rộng phạm vi file chỉnh sửa.
